Crispy Crave - Template Documentation

Welcome to the official documentation for the Crispy Crave Fried Chicken Takeaway & Delivery HTML5 template.

1. Structure & Pages

  • index.html: Home Page 1 featuring the classic hero, bestseller cards, stats, and 7 sections.
  • home-2.html: Home Page 2 with split screen hero, category cards, secret recipe story, lightbox gallery, and 7 sections.
  • menu.html: 5 dedicated food category sections with instant add-to-cart toasts.
  • offers.html: 5 sections highlighting daily specials, family buckets, and weekend discounts.
  • about.html: 5 sections detailing company history, quality promise, and brand values.
  • contact.html: 5 sections including contact cards, validated contact form, interactive map, and takeaway CTA.
  • 404.html: Custom error page with recovery navigation.
  • coming-soon.html: Teaser countdown page with newsletter sign-up.

2. Color Theme Customization

All colors are centrally declared via CSS variables in assets/css/style.css:

:root {
  --primary: #C62828;      /* Brand Deep Red */
  --secondary: #FFB300;    /* Golden Yellow */
  --accent: #F57C00;       /* Warm Orange */
  --bg-main: #FFF8EF;      /* Light Cream */
  --text-main: #1D1D1F;
}

3. Dark Mode & RTL Toggling

Dark mode is toggled using the header button and applies the [data-theme="dark"] attribute to the <html> element. Preferences are automatically remembered across visits via localStorage.

RTL mode is toggled via the earth icon button, updating the dir="rtl" attribute and loading specific RTL mirror alignments from assets/css/rtl.css.

4. Testing & Browser Support

Tested and verified across all modern desktop and mobile browsers (Chrome, Firefox, Safari, Edge) from 360px viewport widths to 4K displays.
